# Global Seed Company

A React + TypeScript + Vite starter website for Global Seed Company.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Customize first

- `src/data.ts`: replace all demonstration seed records with verified company products and specifications.
- `src/App.tsx`: update company story, contact details, and page content.
- `index.html`: update page title and SEO description.
- `src/styles.css`: edit brand colors and visual styling.

## Important

All seed names, maturity periods, seasons, and characteristics currently shown are demonstration content only. Replace them with company-approved, verified information before publishing.

The contact form is a frontend demo and does not send email. Connect a secure backend or form service before using it for real customer inquiries.

The catalog is an interactive two-page browsing experience with previous/next controls. It is a lightweight starting point; a realistic animated page-flip library can be integrated in a later iteration.
